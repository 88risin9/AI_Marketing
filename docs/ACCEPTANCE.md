## 实际浏览器流程

在与正式数据库隔离的“虚构示例”空间中操作：

1. 上传 `assets/example.xlsx`，预览 3 行。第三行列出采购价、币种、起订量、交期、电压、曲线、分断能力缺失，未补造；确认导入后产品库从 3 条变成 6 条。
2. 新建客户 `Seabrook Electrical (Fictional QA)`，联系方式使用 `example.com`，新建“虚构验收 · 1000 pcs MCB”询盘，保存完整英文原文。
3. 点击“演示提取（非真实模型）”，得到 1000 pcs、1P、16 A、230 V AC、C curve、6 kA、within 30 days。每条展示可核对的原文。页面明确提示演示输出不属于真实模型验收。
4. 保存分析，查看候选。2P/32A/400V 产品显示极数、电流、电压冲突，复选框禁用。C16-1P 的 AC 属性及交期显示待确认，未显示为完整匹配。选择本次导入的产品 4，填写明确标注的虚构人工核实说明，再确认。
5. 创建 `QT-00002 / V1`：1000 pcs × 2.50 USD，采购 8.5 CNY，汇率 1 CNY = 0.14 USD，其他成本 20 USD。报价 2500.00 USD，预估毛利 1290.00 USD、51.60%。故意漏填付款条件，页面显示必填提示、审核按钮禁用。
6. 编辑为 V2，填写英文付款条件与客户备注。V2 初始仍为草稿，人工审核后允许正式导出；V1 原样保留。
7. 打开内嵌英文客户预览，并实际点击“导出英文 PDF”。服务端 PDF 请求成功。相同报价导出留档 `output/pdf/quotation-example.pdf`：1 页，已用 Poppler 渲染并查看，文字、金额、表格、页码可读，无重叠或截断。PDF 使用嵌入字体，不依赖阅读器下载字体。
8. 跟进状态保存为“跟进中”，下次日期为 2026-09-18，备注注明没有实际发送邮件。
9. 停止服务进程，再启动。浏览器重新加载后，客户、原文、已确认产品、V1/V2 报价、跟进记录及日期仍在。浏览器没有应用 JavaScript 错误。

正式空间仍为空，没有写入虚构业务。PDF 和邮件均没有发送给外部收件人。

## 自动验证覆盖

| 验收关注点 | 结果与方法 |
| --- | --- |
| 缺参数、不编造 | 缺失值为空；原文证据必须存在且支持字段值；错误数值、错误单位、伪造证据被拒绝 |
| 参数冲突 | 同型号不覆盖极数/电流/电压等冲突；AC/DC 冲突、非 MCB 类别冲突可识别；无产品或全冲突给出明确提示 |
| 复杂需求 | 范围、AC/DC、特殊接法不被截成标量；多组需求提示拆分并阻止合并选型 |
| 产品导入 | CSV/Excel 往返、前导零、原始单位、公式拒绝、损坏文件、扩展参数、缺失提示、整批原子提交 |
| 金额 | Decimal 运算、逐行四舍五入、JPY 位数、汇率方向、MOQ、缺成本不报完整毛利、非法数值拒绝 |
| 正式报价 | 必填项、空白型号、选型审核、未审不能标记发送；改版一律草稿；需求或产品变更后须复审 |
| 历史与保密 | 产品更新不改历史快照；HTML/PDF 顶层内部字段与扩展参数中的内部备注均不导出；文本检查没有采购成本、汇率或毛利 |
| 模型错误 | 超时、HTTP 错误、坏 JSON、拒绝/截断、证据校验失败；错误不含密钥/服务商原始正文；原文与既有分析保留 |
| 人工功能 | 无密钥时仍可新建客户、录入询盘、手工整理、报价、跟进；正式空间不允许演示提取 |
| 备份恢复 | 版本化 JSON、业务空间隔离、关联校验、恢复前自动备份、原子替换；损坏记录、错误总额、缺条款的已审报价拒绝恢复 |
| 访问边界 | 仅监听本机；不信任 Host、跨来源写请求和缺少本地请求头均被拒绝；密钥不进入业务备份或前端状态 |
| 效率记录 | 演示不计入真实效率；无人工基准或实际耗时不计算节省时间 |

## 本次验证中修复的问题

- Excel 工作表缺少尺寸元数据导致读取异常：改成兼容缺失尺寸的有界迭代。
- 数值截取可能丢失范围或 AC/DC 属性：结合完整原文上下文核验，不丢弃关键限定。
- 扩展规格可能混入内部备注：客户导出采用五个 MCB 技术参数的明确允许列表。
- 恢复备份可能引入被破坏的报价金额/条款：重新校验金额、成本和已审必填项，再执行替换。
- 全空格型号绕过必填检查：保持原字符串，但按去空格后的内容校验。
- 待办统计曾把历史草稿也计算为待审核：改为只统计每份询盘的最新报价版本，并把待办按钮指向该版本。
- PDF 对阅读器语言包的依赖：改为嵌入本机 Unicode TrueType 字体，重新渲染检查。

## 第一版明确限制

- 一次处理一组产品需求，多组需拆分。只自动核对 MCB 小类的五个关键参数，认证、库存、交期等由人工核实。
- 包装单位换算、自动汇率、自动发送邮件未实现；金额和汇率均由用户确认。
- 扩展技术参数可保存和内部查看，当前客户 PDF 只导出五个已支持参数。
- 真实供应商资料、正式公司英文抬头、真实成本与商业条款仍须用户填写。
- 仅供本机单人使用；无多人认证、公开部署、自动获客或进销存。
