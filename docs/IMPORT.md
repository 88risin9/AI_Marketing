# 产品资料导入

## 文件

- `assets/products.xlsx`：正式业务空白模板，建议优先使用。
- `assets/products.csv`：相同表头的 UTF-8 CSV 空白模板。
- `assets/example.xlsx`、`assets/example.csv`：三条明确标注的虚构 MCB 资料，用于示例空间演练。

Excel 模板含“产品资料”和“填写说明”。从“产品资料”第 2 行填写，每行一个产品。请保持第 1 行表头，先在网页上传预览，修正错误，再确认导入。最多 2000 行、100 列、5 MB。第一版不读取旧版 `.xls`，请另存为 `.xlsx`。

## 字段说明

| 字段 | 填写规则 |
| --- | --- |
| 供应商、产品名称、英文名称 | 据实填写，英文名称供客户报价使用 |
| 型号 | 保留原型号，作为文本填写，不能仅凭相似型号认定可替代 |
| 分类 | 产品子分类，例如 `MCB`、交流充电桩、真空断路器、配电变压器 |
| 极数 | 例如 `1P`、`2P`，依原资料填写 |
| 额定电流(A)、额定电压(V)、分断能力(kA) | 普通数值的单位已在表头固定；复杂范围可保留文字，匹配时列为待确认 |
| 脱扣曲线 | 例如 `C`；不得从型号自动猜测 |
| 计量单位 | 按原资料保存文本，例如 `pcs`，不自动换算箱、包、件 |
| 采购价 | 非负数，不加货币符号、千位逗号或单位，最多 8 位小数 |
| 采购币种 | `CNY`、`USD`、`EUR`、`GBP`、`JPY`、`AUD`、`CAD`；缺少时留空 |
| 最小起订量 | 大于零的数量，与原计量单位一致，未知留空 |
| 交期 | 保留供应商提供的交期文字及前提条件 |
| 资料来源 | 文件名、资料页、供应商邮件日期或其他可追溯出处 |
| 资料更新时间 | 日期或时间，建议 `YYYY-MM-DD` |
| 扩展参数(JSON) | 例如 `{"frequency_hz":"50/60","mounting":"DIN rail"}`；也可以新增 `参数:frequency_hz` 列 |

资料缺失可以导入，预览和产品页面会标出待补字段。数值格式无效、重复表头、未知列或相同参数互相冲突，会显示为错误。批量确认须整体通过验证，不会只保存一部分。相同供应商、型号、规格和单位在同一文件出现多次，会提示检查重复；同型号的不同规格按独立变体保存，不合并价格。

预览会展示分类、规格、原始单价、资料日期及来源，可搜索定位具体型号。采购单价保留原始小数精度，例如 `2.915` 不会在导入时改成 `2.92`；人民币报价中的 `RMB` 应规范填写为币种 `CNY`，原报价口径可保存在扩展参数与来源说明中。

## 四大产品类别与目录系列

产品资料库支持低压电器、充电桩、中压电器、输配电四个大类，可按子分类、价格状态和资料类型筛选。编辑产品时可以调整分类、补充采购单价和币种；没有价格时留空，页面显示“价格待录入”，不会当作零成本。

“目录系列”记录保存目录范围、可选配置及出处，不代表已确定的订货配置。即使部分参数相同，自动匹配也会要求确认具体型号和配置。已有报价中的明确规格标为“报价规格”，价格、单位和原文独立保留；不能把一个规格的价格套用给整个系列。

批量导入可在原模板中增加以下可选列：`产品大类`、`资料类型`、`目录摘要`、`待确认事项`。资料类型填写 `catalog_series`（目录系列）、`quote_variant`（报价规格）或 `product_variant`（具体产品规格）。也可在扩展参数 JSON 中填写对应的 `product_family`、`record_type`、`source_specification`、`review_notes`。不要同时填写相互冲突的值。

同型号可能对应不同产品、安装形式或目录编号，不能只按型号去重。跨目录同一产品保留各自的来源和参数差异，待供应商确认后再确定订货资料。

## 用供应商资料替换示例产品

在示例测试空间导入时，可勾选 **替换预置示例产品**。系统先把当前空间的全部业务资料备份到 `backups/`，再一次性归档明确标注为虚构的 `DEMO-*` 产品并导入新产品。归档产品默认不显示，也不能用于新的选型、研究任务、采购页或报价；产品页的“显示已归档产品”可查看原记录。原有询盘、历史报价、研究结果与已批准页面快照保留，正式资料空间不受影响。

此选项不会覆盖之前导入的真实供应商资料。重复导入仍会新增记录，请先检查现有资料。需要撤回整次操作时，在同一空间恢复自动生成的 `demo-before-product-replacement-*.json` 备份。

当前应用直接导入 CSV/XLSX，不直接识别 PDF。PDF 报价表需先核对并整理为模板，尤其检查跨页分类、同型号不同规格、价格小数位和原文冲突。记录源文件、页码和行号；原文缺失的 MOQ、交期、认证或技术参数应留空，不能由相似型号补猜。其他产品分类可以保存，自动参数匹配仍主要面向 MCB，不能据此认定其他品类已完成技术选型。

## 保留型号和单位

XLSX 的型号和单位已预设文本格式。CSV 不保存单元格格式，Excel 直接打开 CSV 可能把 `0016` 改成 `16` 或把型号转成日期。应用会拒绝 XLSX 中非文本的型号和单位。仅修改格式不能找回已经丢失的零，请对照原始资料修正。

应用保存型号和单位的大小写及首尾空格；请在预览中确认原文是否有多余空格。计算和选型过程中另行检查单位，不悄悄改写原始资料。

Excel 公式行会被标记为错误，请先粘贴为纯值。CSV 内容按文本读取，疑似公式开头会提示确认。下载 CSV 的字符串输出防护会阻止它在表格软件中作为公式执行。

## 示例说明

三个虚构型号分别为：

1. `DEMO-MCB-C16-1P`：1P / 16 A / 230 V / C 曲线 / 6 kA。
2. `DEMO-MCB-C32-2P`：2P / 32 A / 400 V / C 曲线 / 6 kA，用于验证硬参数冲突。
3. `DEMO-MCB-UNKNOWN`：1P / 16 A，其余关键参数、价格及交期为空，用于验证缺失提示。

供应商、型号、参数和价格均为虚构，不构成认证、库存或供货承诺。请在应用的示例空间使用，正式空间只导入经你确认的真实资料。
