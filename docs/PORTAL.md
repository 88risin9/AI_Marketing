# 买家采购页：本地预览与数据边界

## 当前可以使用的功能

启动 V2 后，内部工作台仍在 `http://127.0.0.1:8765`，独立买家预览服务在 `http://127.0.0.1:8766`。两个服务共用本地 SQLite 数据，但拥有不同的路由和数据读取接口。

**目前所有买家链接均为本地预览，尚未公开部署。海外买家不能访问你的 `127.0.0.1` 链接。** 界面上的分享链接和嵌入代码用于检查承接流程；完成后续部署才能用于独立站、社媒或真实买家。

### 建立页面

1. 在内部「买家采购页」选择已有产品，填写页面标题和买家类型。
2. 选择「人工辅助模板」，或在模型配置完成后选择「AI 辅助草稿」。AI 页面动作单独调用模型一次，在活动记录中记录用量；不隐含消耗某项研究任务的预算，也不显示未经配置的费用。
3. 逐项检查对外预览。确认后才开放随机链接。未审核草稿无法通过买家端访问。
4. 点击本地预览，或复制同一页面的链接、iframe 入口。

AI 辅助页面生成复用 V1 服务端模型配置，真实调用 OpenAI Responses 或兼容 Chat Completions 接口。模型只在受限的标题、说明和下一步用语中选择，并排序所选产品；所有产品事实仍直接来自选定资料。模型不能自由生成价格、认证、库存或交期承诺。未配置模型时，人工模板仍可使用；模板不会标成 AI 生成。模型出错时不保存误导性页面，不改动产品资料。

### 从买家提交进入原有询盘流程

买家无需注册，可以填写型号或需求、数量与单位、期望交期、联系方式，或上传采购清单。只询问少量必要信息：名字或公司、有效格式的邮箱、需求描述/型号/采购清单三者之一，以及使用资料回复本次需求的确认。

成功提交后：

- 原文、上传清单解析后的文本、客户资料在一个数据库事务中保存；发生写入错误时整体回滚。
- 新记录出现在同一资料空间的「客户与询盘」中，状态为「待补充」，来源为「买家采购页」，内容标明人工提交且未核验。
- 在内部打开询盘并点击已有的 AI 提取按钮，复用 V1 的需求整理、来源校验、匹配、人工审核和报价流程。**匿名提交本身不会自动触发付费模型调用。** 模型失败也不会丢失原文。
- 浏览器只得到通用收件回执，不返回内部记录 ID、客户数据或读取询盘的链接。生成回执不代表已确认订单、价格或交期。

同一个浏览器提交标识重试时不会重复建档。买家的邮箱仅按格式检查，既不代表身份核验，也不代表可送达性已验证。

### 清单格式

支持 `.csv`、`.xlsx`、`.txt`，单个文件最大 1 MB。表格最多 200 行、30 列，总文本最多 16,000 字符。XLSX 只接受一个工作表；公式、宏、异常压缩文件和范围外的稀疏单元格会被拒绝。CSV 中类似公式的单元格也会被拒绝，请先粘贴为值。

上传文件只在内存中读取，不保留原始二进制文件；清单文本与原始文件名保存在内部询盘。型号前导零在文本单元格中保留。Excel 已将型号转换成数字时无法推断丢失的前导零，请把型号列保存为文本。

## 审核与历史

- 买家页面采用独立的公开快照。仅产品英文名、型号、分类、单位、资料日期，以及极数/额定电流/额定电压/脱扣曲线/分断能力五项参数进入公开快照。
- 产品的采购价格、币种、供应商、原始资料来源、内部备注、自定义扩展参数不会进入公开快照；研究判断、其他买家及报价记录也不能通过买家服务读取。
- 缺少的参数显示 `To be confirmed`。示例资料空间始终显示 `FICTIONAL DEMO`。
- 修改页面内容或页面中的产品选择后，页面重新成为草稿，公开链接暂时停止提供内容，须重新审核。审批接口要求确认及刚刚预览的版本时间，避免审批期间并发修改造成误发布。
- 更新产品库不会改变此前审核的页面快照；编辑页面时才重新取得产品数据。每次审核保留历史快照。
- 「取消展示」立即停止该链接的公共读取。已有客户询盘继续保留在内部。

## 当前的访问控制

公开服务只注册以下接口：

| 路径 | 用途 |
| --- | --- |
| `GET /p/<随机标识>` | 已审核页面 |
| `GET /api/public/pages/<随机标识>` | 严格白名单快照与短期表单令牌 |
| `POST /api/public/pages/<随机标识>/inquiries` | 只写入本次采购需求 |
| `GET /assets/buyer.js`、`buyer.css` | 两个固定买家端静态资源 |

没有客户、询盘、研究、报价或备份的公开读取接口。公开接口不接受资料空间选择，所属空间由已审核链接决定。未知、草稿、取消展示或快照结构异常的页面均停止提供内容。恢复备份时同样验证公开快照的字段白名单；运行时读取再次检查。

写入必须通过同源检查和 30 分钟有效的表单令牌，且默认每个地址每分钟最多 5 次提交。原始上传内容不出现在访问日志或错误日志。安全响应头限制脚本来源；没有第三方分析脚本、自动外联或支付流程。

## 公开部署前需要另行完成的配置

本次不包含部署。正式上线时需要明确配置：

1. 独立公开域名、HTTPS、生产 WSGI 服务及反向代理；只公开买家 app。内部 app 保持本机或受认证保护的私有网络访问，不能直接公开端口 8765。
2. 将买家 app 的本机 Host 白名单、同源要求、iframe `frame-ancestors` 改为实际公开域名与获准嵌入的独立站来源。当前默认仅支持本机预览，修改绑定地址并不足以上线。
3. 将内部展示的本地分享基础地址替换成实际 HTTPS 地址；再验证独立站 iframe、移动端和社媒浏览器。
4. 按可信反向代理配置实际客户端地址、持久化限流与反垃圾策略。当前进程内限流用于本地预览，重启会清零；不要信任任意传入的 `X-Forwarded-For`。
5. 设定生产数据的访问权限、备份、保留/删除方式，以及正式展示的隐私说明、公司身份和联系方式。

公开买家页面不提供私人询盘或报价查询。若今后增加此能力，必须另行实现每位买家的身份验证与记录级授权，不能复用公开采购页面链接作为私人资料访问凭证。
