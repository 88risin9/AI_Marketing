# V2 买家研究与开发材料

## 能力边界

任务以选中的产品快照、用户指定市场/买家类型及供货条件为范围。产品快照仅包含名称、型号、分类、计量单位和五个技术参数，不向模型发送采购价、供应商信息、其他客户或报价。

真实任务流程：AI 保存搜索计划 → 调用搜索服务 → 保存搜索结果 → 读取公开网页 → 校验 AI 返回的逐字事实/引文 → 同域名或同名称去重 → 在预算内补读页面、补充检索 → 保存企业卡片与剩余缺口。业务分类、产品相关性和采购需求均是待人工审核的判断；公开经营信息不证明已有采购意向。

公司名称、国家、经营业务和相关产品线索必须各有逐字来源。引用或产品编号不正确时不保存该 AI 结果，保留原网页以供重试。跨页证据补充缺失事实；不同所在地/业务/身份判断会标记冲突。目录、供应商、竞争者和明显无关对象不显示成匹配买家。品类线索仅支持中等产品相关度，不代表参数兼容。自动中优先级须同时满足潜在买家分类、中等以上产品相关度、证据充分度和联系可行性；缺少联系入口或来源冲突时自动建议为低。用户明确调整的优先级继续保留，同时显示自动建议及依据。

## 本地配置

沿用 V1 的 `AI_PROVIDER`、`AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY`、`AI_TIMEOUT`。服务端单独读取以下 `.env` 配置；环境变量优先，文件必须仅当前用户可读（`chmod 600 .env`）。密钥不要填在网页或聊天里。

```dotenv
RESEARCH_SEARCH_PROVIDER=brave
RESEARCH_SEARCH_API_KEY=
RESEARCH_READER_ENABLED=true
RESEARCH_HTTP_TIMEOUT=15
```

- 搜索提供商：`brave`、`tavily`，或 `disabled`。所选服务的密钥填入同一个 `RESEARCH_SEARCH_API_KEY`。
- Brave 调用 Web Search；Tavily 固定 `search_depth=basic`，不请求自动生成答案或原网页内容。
- 网页读取由服务端执行，可配置开关和 5–30 秒超时。不需要另一个网页读取密钥。
- 当前只读取公开 HTML/纯文本，不运行网页 JavaScript，不登录，不绕过拒绝访问。不支持直接解析 PDF 产品目录；可以人工摘录并填写 PDF 原链接。
- 未配置搜索/模型时，界面分别显示缺少能力。人工企业资料可立即保存；提供网页种子网址后，可以真实读取网页，得到标注“尚未 AI 研判”的来源记录。它不是完整 AI 联网研究。

## 预算、停止与恢复

单个任务最多研究目标 20 家，搜索上限 20 次、模型上限 40 次、网页读取上限 50 次。预算在请求前持久化；失败、超时及被取消的在途请求也计数。AI 开发材料使用关联研究任务剩余模型预算。没有配置有效模型时不会产生调用次数。

网页次数按一次读取操作计算；每次最多跟随 3 次重定向。单网页最大 2 MB，保存最多 16,000 字符可读正文；每任务最多保存 50 页。模型只看到当前任务必要资料和正在分析的一页，开发材料只看到该企业引文及相关产品。

取消会立即阻止下一次调用，已发出的请求无法撤回；返回后仍保存该次来源/结果和用量。重启会把运行中任务改为暂停；点击继续恢复。失败重试复用已有页面和企业档案，不重置累计用量。失败的搜索仍保留当前查询位置，网页失败链接可在重试时重新排队。预算用尽后状态为已停止/完成，缺口中说明停止原因；不会为满足数量虚构企业。

搜索与页面读取仅使用已配置服务及公开 HTTP/HTTPS；禁止本机、内网、特殊地址、凭据网址和非 80/443 端口。域名所有解析地址须为公网，连接固定到已检查的 IP；每次重定向重新校验。不使用环境代理，不把搜索密钥转发到重定向目标。外部页面文本始终作为不可信资料，不能调用任何工具或改变任务预算。

## 人工审核与开发材料

1. 打开企业卡片，核查名称、所在地、业务、原文和日期；接受或排除需填写原因。
2. 如人工资料与已有域名相同，合并到同一档案，保留先前来源与历史。
3. “人工辅助模板”不调用模型，也不伪装为 AI。它优先引用人工提供的简短片段，再使用已校验的产品经营线索；只有未分析的原网页时不引用导航或页头，而是询问是否经营相关品类。人工片段明确标为尚待核验。
4. “AI 开发材料”让模型选择已校验来源片段、产品及下一步，再由程序组装克制的英文草稿。这样可以避免自由生成的价格、认证、现货和交付承诺。选择结果仍需要人工复核。
5. 修改内容先保存，再单独审核；内容更改会撤销审核。所有邮件都是草稿，不执行发送。
6. 实际发送后在企业档案手动改为“已联系”，收到回复后再更新；生成邮件不会改变联系状态。

公开通用邮箱只能标为通用邮箱，未验证可送达，也不代表采购负责人。个人邮箱不会自动从页面抽取为联系对象。联系页面来自实际页面链接，不能由模型编造。

## 统计

统计当前资料空间中去重的真实网页/人工企业记录，不计标为演示来源的档案。认可数为当前接受状态；联系、回复、有效询盘按人工记录的曾经发生日期去重。回复率 = 回复企业数 / 实际联系企业数；有效询盘率 = 有效询盘企业数 / 实际联系企业数。分母为零显示暂无数据。没有可靠单价配置，不计算费用。
