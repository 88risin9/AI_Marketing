## 尚需配置和验证

1. 在本机 `.env` 填写模型服务的 `AI_API_KEY`，确认账号可用模型；保留现有 OpenAI/compatible 接入方式。
2. 在同一文件填写 Brave 或 Tavily 的 `RESEARCH_SEARCH_API_KEY`，并匹配 `RESEARCH_SEARCH_PROVIDER`。不要在聊天或前端输入密钥。
3. 在小预算真实任务中验证搜索发现、真实模型逐条判断、补充检索及开发材料。逐条人工检查名称、官网归属、经营线索和联系方式；不足结果如实保留。
4. 配置真实产品、供应条件和用户选择的正式市场；英国和当前示例产品仅用于流程测试。
5. 如需海外买家访问，另行部署独立买家服务、域名/HTTPS及生产访问保护，见 [买家页上线说明](PORTAL.md)。当前不支持直接解析网页 PDF 目录，可人工摘录；依赖 JavaScript 或拒绝自动访问的网页可能无法读取。
